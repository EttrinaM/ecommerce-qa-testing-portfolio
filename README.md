# E-Commerce QA Testing Portfolio

## Overview
This project demonstrates end-to-end manual QA testing of an e-commerce application.

## Scope
- Login functionality
- Product catalog
- Add to cart
- Checkout process

## Skills Demonstrated
- Test case creation
- Functional testing
- Regression testing
- Bug reporting
- API testing (Postman)
- SQL data validation

## Tools Used
- Postman
- SQL (PostgreSQL)
- GitHub

## Project Structure
- test-plan
- user-stories
- test-cases
- bug-reports
- api-testing
- sql-validation

## Goal
To simulate real-world QA testing experience and demonstrate testing workflow.
