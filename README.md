# E-Commerce QA Testing Portfolio

## Overview
This project demonstrates end-to-end manual QA testing of an e-commerce application.

## Scope
- Login functionality
- Product catalog
- Add to cart
- Checkout process

## Skills Demonstrated
- Test case creation
- Functional testing
- Regression testing
- Bug reporting
- API testing (Postman)
- SQL data validation

## Tools Used
- Postman
- SQL (PostgreSQL)
- GitHub

## Project Structure
- test-plan
- user-stories
- test-cases
- bug-reports
- api-testing
- sql-validation

## Test Execution Summary

All core user flows including login, cart, and checkout were tested and passed successfully.

A usability-related defect was identified in checkout field validation and documented in the bug reports section.
