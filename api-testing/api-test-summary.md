# API Testing Summary

## Objective
Validate API endpoints, response status codes, and data accuracy for an e-commerce system.

## Tool Used
- Postman

## Test Scenarios

| API Test ID | Method | Endpoint | Expected Result | Status |
|---|---|---|---|---|
| API-001 | GET | /products | Status 200 and product list returned | Not Run |
| API-002 | GET | /products/1 | Status 200 and product details returned | Not Run |
| API-003 | POST | /carts | Status 200/201 and cart created | Not Run |

## Validations
- Status codes
- Response body structure
- Required fields
- Data types
- Product data accuracy
