# Test Plan: E-Commerce Application

## Objective
To validate core functionality of an e-commerce system including login, product selection, cart, and checkout.

## Scope

### In Scope
- Login functionality
- Product catalog
- Add to cart
- Remove from cart
- Checkout process
- Order confirmation
- Error validation

### Out of Scope
- Payment processing
- External integrations

## Testing Types
- Functional Testing
- Negative Testing
- Regression Testing
- UI Testing

## Test Environment
- Browser: Chrome
- OS: Windows
- Application: SauceDemo

## Entry Criteria
- Application is accessible
- Test cases are created

## Exit Criteria
- All critical test cases executed
- Bugs documented
