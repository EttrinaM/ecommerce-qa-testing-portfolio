# User Stories

## US-001: Login
As a user, I want to log in so I can access products.

**Acceptance Criteria:**
- Valid login redirects to product page
- Invalid login shows error message

---

## US-002: Add to Cart
As a user, I want to add items to my cart.

**Acceptance Criteria:**
- Item is added successfully
- Cart count updates

---

## US-003: Checkout
As a user, I want to complete checkout.

**Acceptance Criteria:**
- User enters required info
- Order is confirmed
